
# Temperature Conversion Notebook

[![Launch with Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/Arian858/temperature-conversion-notebook/HEAD?urlpath=lab/tree/notebooks/temperature_conversion.ipynb)

A practical Python project demonstrating temperature conversion between Celsius and Fahrenheit through reusable functions, input validation, automated testing, and interactive execution.

## Overview

The Temperature Conversion Notebook is a small Python programming project designed to demonstrate fundamental programming concepts through a practical application.

It provides a structured implementation of temperature conversion operations, with an emphasis on code reusability, validation, testing, and readability.

## Features

- **Bidirectional Conversion:** Convert temperatures between Celsius and Fahrenheit.
- **Reusable Functions:** Implement conversion logic using modular Python functions.
- **Input Validation:** Handle invalid data types and non-finite numerical values.
- **Automated Testing:** Verify conversion accuracy using assertions.
- **Interactive Execution:** Allow users to enter temperatures and select conversion directions.

## Conversion Formulas

**Celsius to Fahrenheit**

F = (C × 9/5) + 32

**Fahrenheit to Celsius**

C = (F − 32) × 5/9

## Getting Started

### Option 1: Run online with Binder

Click the Launch with Binder button at the top of this README.

Binder will create a temporary cloud environment and open the notebook in JupyterLab.

Run the notebook cells sequentially to explore the implementation and execute the examples.

### Option 2: Run with Google Colab

1. Open Google Colab.
2. Select File → Open notebook.
3. Choose the GitHub tab.
4. Find this repository and select `temperature_conversion.ipynb`.
5. Execute the notebook cells.
